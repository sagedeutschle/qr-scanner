One-time setup

Apple only lets software read your listening history through its official API, and the API requires a (sadly, paid) Apple Developer key to sign requests. Paste yours below — it's saved in this browser only and is never sent anywhere except used locally to sign requests to Apple.

How to get these (≈5 min, needs Apple Developer Program — $99/yr)
  1. Join the Apple Developer Program with your Apple ID.
  2. Go to Certificates, Identifiers & Profiles → Keys, create a key, and enable MusicKit / Media Services on it.
  3. Download the .p8 file (Apple only lets you download it once — keep it safe) and note the Key ID.
  4. Your Team ID is on the Membership page.
Don't want to pay Apple? Free ways to get (almost) the same thing

Apple actually does build playlists from your listening — the features are just weirdly buried:

  • Flip the switch that gates all of it: iPhone → Settings → Music → Use Listening History must be ON.
  • Made For You mixes: Music app → Home tab → scroll to the "Made For You" section: Favorites Mix, New Music Mix, Chill Mix, Get Up! Mix, Heavy Rotation. They regenerate weekly from your listening.
  • Discovery Station: search "Discovery Station" in the Music app — endless personalized radio made only of songs you haven't played. There's also "Your-name's Station" for the familiar version.
  • Shortcuts recipe (iPhone, free): Shortcuts app → new shortcut → add Find Music (filter: Last Played is in the last 30 days, sort by Play Count, limit 25) → add Add to Playlist. Run it any time for an instant "on repeat" playlist from your library.
  • Mac Smart Playlist: Music app on a Mac → File → New → Smart Playlist → rules like "Last Played in the last 30 days, sorted by plays, limit 25". It updates itself forever and syncs to your phone.
